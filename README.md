# 钢铁前线 STEEL FRONTLINE

一款完全离线的网页版第一人称战术射击游戏（CS / 使命召唤风格），基于 **Three.js** 构建，
所有资源（引擎、纹理、音效）均已本地化，**无需联网**即可游玩。

## 运行方式

**方式一（推荐）**：双击 `start.bat`，浏览器会自动打开游戏。

**方式二**：在项目目录执行 `node server.js`，然后访问 http://localhost:8080

> 注意：游戏使用 ES Modules，直接双击 index.html 会被浏览器安全策略拦截，必须通过本地服务器访问。

## 游戏内容

### 🏜️ 竞技模式「沙漠街区」（dust2 风格）
- 96×72m 经典对称竞技图：中路长通道、A 大道、B 隧道、箱子掩体与高台
- 攻占 A / B 两个目标点，抵御 8 波敌人

### 🗺️ 大战场模式「钢铁前线」
- 400×400m 起伏丘陵大地图：战壕、碉堡、观察塔、坦克残骸、集装箱阵地
- 攻占全部 5 个据点，抵御 12 波敌军（含火箭兵）

### 🔫 武器系统
- **M4A1 消音突击步枪**（自动连射）/ **USP 手枪** / **AWP 狙击枪**（可开镜）/ **碎片手雷**
- **下载的高精度枪械建模**：M4A1（FBX 转换链修复：两遍导出+索引对齐，13 部件 27774 顶点完全干净，**标准枪口无消音器**）、手枪（0.58m）、狙击（1.37m）
- **真实持枪倾角**：枪械绕 X 轴倾斜 28-31°（CS 式持枪姿态）；步枪/手枪开镜时枪略偏右下不遮挡准星，狙击开镜只显示瞄准镜
- **手感调校**：射速 0.095s、后坐力曲线（0.015/0.018/0.042）、准星扩散回弹、开枪枪口随机微晃
- 狙击开镜只显示瞄准镜遮罩（径向渐变透光）；真实弹道散布、CS 风格后坐力（0.012 rad 上抬 + 连射累积）
- 曳光弹（主亮线+前端亮点）、高温铜色弹壳、弹着火花；换弹动画、V 键检视、补给点

### ⚙️ 战斗配置（开始前可选）
- **敌人规模**：标准 / 大规模（×1.6）/ 地狱（×2.2）
- **友军人数**：0 / 2 / 3 / 5 人（大战场）

### 💣 爆破模式（竞技场）
- 未占领目标点内按 **E 下包**（3 秒读条）→ 炸弹放置（45 秒倒计时、警示灯闪烁）
- 引爆后 AOE 清场（9m 内敌人 250 伤害）+ **爆破占领目标点**
- **敌人拆包 AI**：敌人靠近炸弹自动拆包（4 秒），HUD 显示炸弹倒计时
- 友军小队：两种模式都按配置生成（0-5 人），跟随编队、共享目标集中火力

### 🤖 敌人与友军 AI
- 5 种兵种：突击兵 / 重甲兵 / 狙击手（激光警告+吉利服）/ 自爆兵（炸弹背包）/ 火箭兵（火箭筒），整体放大 8%
- **敌我分辨**：敌人头顶红色菱形标识、友军蓝色菱形标识（穿透显示、随距离缩放、呼吸脉冲）
- 巡逻 → 追击 → 攻击状态机、视线检测、听到枪声调查（原地转头搜索）
- **绕障寻路**（墙前切线滑动）、远距侧移包抄、受击后撤、移动射击精度惩罚
- **被击中呼救**：35m 内同伴协同进入追击；受击撤退优先退向矮掩体（沙袋/箱子）
- **大战场友军小队**：跟随编队（保持间距不扎堆）、共享目标集中火力（射线/爆头/击杀入账）

### 🚁 载具系统（大战场）
- **战术吉普 ×2** / **武装直升机**：第三人称跟随视角、W/S 油门、A/D 转向、Shift 加速、Space/Ctrl 升降
- **耐久系统**：吉普 350 / 直升机 420 HP，敌人子弹会攻击载具（火花+金属音），**打爆 = 爆炸 AOE**（车毁+范围伤害）
- **撞击伤害**：高速撞击可撞死敌人（速度相关+击飞）；地形平滑贴地（崎岖不悬空）
- 靠近按 E 上车，驾驶中 E 下车

### ⛰️ 大战场场景
- **地形高低差显著**：起伏增强 + 四座高耸山峰（范围 15.5m）
- **树木建模重做**：主干+斜枝+多球树冠（60 棵）
- 营地细节：帐篷×4、战壕木板路、电线杆+电线（沿道路）、沙袋/油罐/烟囱/废墟楼/岩石/灌木

### ✨ 视听表现
- 实时阴影、HDR 环境光照（0.85）、泛光（0.16）、ACES（曝光 0.95）；**武器材质挂环境反射**（envMapIntensity 0.8-1，金属随环境光影变化）
- 竞技场阳光 1.45 / 大战场 1.8 分图标定；**地面纯哑光** + **bump 视差纹理**（沙粒/草地凹凸）
- 竞技场阳光 1.45 / 大战场 1.8 分图标定，沙地/草地材质压暗——无过曝炫光
- **真实音效样本**（本地 CC0）：24 种枪声、脚步、爆炸、撞击、命中音；战场 BGM 循环
- PBR 真实贴图（Poly Haven CC0）：混凝土 / 集装箱金属 / 木板 / 沙滩
- **Kenney 场景道具（CC0）**：战术卡车（colormap 贴图替换吉普）、路障锥、车残骸、货箱、油罐、烟囱、废墟楼
- 场景装饰：废弃吉普、路灯、广告牌、轮胎堆、铁丝网、弹坑、通讯塔、弹药箱堆、沙袋模型
- 动态小地图、击杀提示、伤害方向指示、低血量红晕、冲刺 FOV、受击/爆炸镜头震动

## 操作
| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| 鼠标左键 / 右键 | 开火 / 开镜瞄准 |
| Shift / Space / C | 冲刺 / 跳跃 / 蹲下 |
| Q / 滚轮 / 1-4 | 快速切枪 / 循环切枪 / 选择武器 |
| R / G / E / V | 换弹 / 投掷手雷 / 交互（补弹）/ 检视武器 |
| M / Esc | 小地图开关 / 暂停 |
